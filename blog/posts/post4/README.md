# Blog 4: New-home prices, mortgage rates, and payment burdens

## Question and main result

Did the decline in U.S. new-home prices after 2022 restore the buying power workers had in 2019? The analysis combines a new dataset of four FRED series covering 2019 Q1 through 2025 Q3. It compares inflation-adjusted prices and earnings, mortgage rates, and hypothetical mortgage payments measured in hours of gross average earnings. October 2025 CPI is missing; the analysis stops at the last complete 2025 quarter.

Start with `blog4.qmd` for the article and `code/analyze.py` for the complete analysis. The three figures, quarterly results, and all numerical statements in the article are generated by that script. The saved article and figures let the existing GitHub Actions workflow publish the post without a Python setup step or a fresh network request.

## Reproduce the saved analysis

Use Python 3.11 or newer. Open a terminal at the root of `Yining-Han-Website`:

```bash
python -m pip install -r blog/posts/post4/requirements.txt
python blog/posts/post4/code/analyze.py
```

These commands use the included raw CSV snapshots; no FRED account, API key, or internet connection is needed after installing the packages. The script resolves file paths relative to its own location, so it also works when launched from another working directory.

The run verifies snapshot hashes, unique dates, complete quarterly coverage, three monthly observations per quarter for CPI and earnings, and the weekly mortgage observation counts. It regenerates all three figures, the quarterly CSV, the summary JSON, and `blog4.qmd`.

To publish the supplied files, simply commit and push them. Python does **not** need to run before publishing. The repository's existing workflow runs `quarto render` and deploys the `docs` output. For an optional local preview with Quarto installed:

```bash
quarto preview blog/posts/post4/blog4.qmd
```

## Refresh the source data

```bash
python blog/posts/post4/code/analyze.py --refresh
```

This makes one CSV request per series to the public FRED download endpoint, replaces the snapshots and source manifest, and regenerates all outputs. The downloaded files include all of 2019–2025; the analysis keeps the fixed 2019 Q1–2025 Q3 window because October 2025 CPI is missing. FRED revisions can change historical values, so use the bundled snapshots to reproduce the submitted version exactly. Review the resulting text and figures after refreshing.

The generated article date is the original publication date. The data retrieval date is read from the manifest. Each request and file hash is recorded in `data/sources.json`.

## Methods and interpretation

- Use the published quarterly median new-home price directly. Average CPI, hourly earnings, and mortgage rates within each quarter, then join on quarter.
- Divide price and earnings by CPI and rebase both series to 100 in 2019 Q1.
- Set the hypothetical loan to 80% of the quarter's median new-home price. Apply the standard 360-month amortization formula using the quarter's average annual mortgage rate divided by 1,200.
- Divide the monthly principal-and-interest payment by average hourly earnings. Repeat with the interest rate fixed at the 2019 Q1 value, keeping prices and earnings unchanged.
- Treat the fixed-rate comparison as a mechanical accounting exercise, not a causal estimate or a personal mortgage quote.

The median covers new homes only and can change with the mix of homes sold. Hourly earnings cover private-sector employees and are gross earnings, not household disposable income. Payments exclude property taxes, insurance, maintenance, fees, and the down payment. The price and rate series are not seasonally adjusted. Freddie Mac changed its survey methodology in November 2022.
