# Blog 2: grading evidence and revision checks

The original screenshots show 8/10, with 0/1 for question/motivation, 0.5/1 for
interpretation/takeaway, and 0.5/1 for substantive actionable insight. The explicit
motivation comment says comparing only a few prices did not require scraping.
No detailed comments were shown for the other two half-point deductions.

The revision changes the question and dataset: it compares title/location and
telecommuting fields across all 19 visible Python.org posting cards, with 17
company-title combinations after merging repeated postings. The collection,
cross-field comparison, and duplicate handling have a purpose in the decision.
It does not try to improve the old fare calculation merely by adding prose.

  illustrative records linked in the article.

  union = 13. Six explicit contradictions are separated from the two cases in
  which a positive flag adds information to otherwise silent short fields.
- The capture date is derived from recorded UTC request timestamps.
- Main figure inspected for labels, counts, and legibility.

- Quarto 1.10.19 successfully rendered the revised article and the blog index
  using the current repository configuration. The original `blog2.html` URL

  for the unrendered older Post 3 is outside this check's scope.
- The blog list contains one revised Blog 2 entry and the other four existing
  articles. Supporting checks and the generated case table use `.txt` files
  so they do not become additional blog entries.
- All local links to the figure, data, R files, and replication guide resolve.
- Desktop and 390-pixel mobile layouts inspected; the table scrolls inside its
  own container without horizontal page overflow. The figure enlarges on click.
- Article prose is approximately 650 words, excluding the table, figure caption,
  and data/replication note. One substantive figure and one linked case table
  support the same screening question.

This checklist records evidence, not an assurance of a particular grade.
